Design Guidelines

デザインガイドライン

英検4級リスニング講座のUIを組み立てるための規約です。配色・文字・部品・アクセシビリティの4章からなり、値はアプリ本体と同じ tokens.css を読み込んで表示しています。ここの見た目が変われば、アプリの見た目も変わっています。

Color1. カラー

ハワイの海と夕焼けを出発点にした配色です。もっとも重要な原則は、同じ色名でも「塗るための色」と「文字にするための色」を分けて持つことです。鮮やかな色をそのまま文字に使うと、明るい背景の上でほぼ読めなくなるためです。

塗るための色（装飾）

面・グラフ・アイコンの地など、文字が乗らない場所に使います。ブランドの鮮やかさはここで表現します。

--sea
海。進捗・情報
--pink
ハイビスカス。達成・現在地
--coral
夕焼け。連続記録
--sun
陽。ごほうび・助言
--green
正解
--grad-sea
装飾グラデ（文字は乗せない）
--grad-sunset
同上

文字を乗せるための色

ボタンやバッジのように白文字を乗せる面は --*-solid と --grad-*-strong、文章やラベルの文字色は --*-text を使います。どちらもライト・ダーク両方で4.5:1以上になるよう決めた値です。

--grad-sea-strong
主ボタン（白文字）
--grad-sunset-strong
強調ボタン（白文字）
--grad-pink-strong
復習ボタン（白文字）
--pink-solid
バッジの地（白文字）
--green-solid
正解チップの地（白文字）

実測コントラスト

下の比率はこのページが読み込んだ実際のトークンから、表示時に計算しています（テーマを切り替えると数値も変わります）。

してはいけない--pink のような鮮やかな色を、そのまま文字色や白文字の下地に使う。ライトテーマで2.4〜3.3:1にしかならず、明るい車内では読めません。
正しい文字色は --pink-text、白文字を乗せる面は --pink-solid。鮮やかな --pink は文字が乗らない装飾だけに使う。

Typography2. タイポグラフィ

本文は Zen Maru Gothic（丸ゴシック）。やわらかさを出しつつ、字面が大きく50代以降でも読みやすい書体です。英字の飾りだけ Pacifico を使い、南国の空気を担当させます。日本語には絶対に使いません。

画面の主役--fs-display / 25px
タブの見出し--fs-h1 / 22px
セクション見出し--fs-h2 / 19px
ボタンの文字--fs-lead / 17px
本文・選択肢--fs-body / 16px
補足説明--fs-sm / 14px
ラベル・バッジ--fs-xs / 12.5px
最小サイズ--fs-2xs / 11.5px
  • 11.5px より小さい文字は使わない。主な利用者は57歳で、運転前後の短時間に見ます。
  • ウェイトは 400 / 700 / 900 の3段階のみ。強調は太さで行い、色を増やさない。
  • 数字が縦に並ぶ場所（点数・日数・時間）は font-variant-numeric: tabular-nums で桁を揃える。
  • 見出しの行間は1.3〜1.35、本文は1.7前後。日本語は行間を詰めると一気に読みにくくなります。

Components3. コンポーネント

ボタン

役割は3段階だけです。1画面に主ボタンは原則1つ。迷わせないことを最優先します。

  • 主（--grad-sea-strong）…その画面でいちばんやってほしい操作。
  • 強調（--grad-pink-strong）…復習など、注意を引きたい操作。
  • 控えめ…戻る・閉じるなど。枠線のみ。
  • 角丸は完全な丸（--r-full）。高さは56px以上、押すと0.97倍に縮む。

カード

情報のまとまりはすべてカードに入れます。角丸は --r-xl(28px)、影は黒ではなく夕焼け色を含んだ影（--shadow-card）を使い、紙が浮いているように見せます。

カードの例

境界は1pxの --line。入れ子のカードは作らない（階層が深く見えると迷います）。

バッジ

状態を短い語で示します。淡い地に濃い文字が基本。白文字にするのは強い通知だけです。

ドリル最高 9 / 10 クリアずみ ＋24 XP きょう

選択肢

正誤は色・枠線・記号の3つで同時に示します。色が見分けにくい人でも判断できるようにするためです。

1I'll go tomorrow.
2I watched a movie.
3It's my sister's.

祝う（モーション）

続けてもらうための演出は、成果に比例させるのが原則です。毎回同じ強さで祝うと、すぐ意味を失います。

  • 正解…ピンポン♪の音と ⭕ のみ。0.2秒。
  • 7割以上…リングが伸び、点数が数え上がり、淡い紙吹雪。
  • 満点・模試合格…リングが金色になり、紙吹雪を増やす。
  • レベルアップ…専用画面に切り替え、光条・メダル・上昇音。ここだけ画面を占有してよい。
時間の決まり要素は0.45秒で下から現れ、0.1秒ずつずらす。演出全体で1秒以内に読み終えられること。待たせる祝福は邪魔になります。
必ず守るprefers-reduced-motion: reduce が有効なら、紙吹雪も数え上げも止めて即座に最終状態を表示する。演出は情報を伝える手段であって、情報そのものではありません。

Accessibility4. アクセシビリティ

「57歳が、運転の前後に、車内の明るい光の下で使う」ことを基準にしています。装飾よりも読めることを優先します。

守っている基準

  • コントラスト比 4.5:1 以上（大きな太字は3:1）をすべての文字で確保。ライト・ダーク両テーマ、全画面で機械的に検証しています。
  • タップ領域は最小44×44px。リンク状のものも高さ44pxを確保します。
  • 色だけで意味を伝えない。正解・不正解は ✓ / ✕ の記号と枠線も併用します。
  • キーボード操作でフォーカス位置が見える。3pxの輪郭線を表示します（下のボタンをTabキーで確認できます）。
  • 読み上げ対応。タブは role="tab" と aria-selected、正誤と進行状況は aria-live で読み上げられます。
  • 動きを減らす設定を尊重。prefers-reduced-motion が有効ならアニメーションを止めます。
44 × 44

運転中の配慮

  • 運転中に使うモードは画面を見なくても完結させる。判定はピンポン／ブブーの音で伝え、解説は音声で流す。
  • 画面を消すとブラウザは処理を止めるため、画面オフで使うモードは音声を1本の連続再生にする（区間制御を挟まない）。
  • 走行中に操作が必要な要素は置かない。外部リンクには操作しないよう注意書きを添える。
